EADME – Application Web de Gestion des Employés et des Rôles
📌 Description du projet

Cette application web permet de gérer les employés d’une entreprise et d’organiser leurs rôles.
Elle offre une interface moderne où chaque employé est affiché sous forme de carte, pouvant être déplacée selon le rôle qui lui est attribué.

🚀 Fonctionnalités principales

➕ Ajouter un employé (nom, email, photo, etc.)

🗂️ Afficher les employés sous forme de cartes

❗ Les employés ajoutés apparaissent d’abord dans la section “Sans rôle attribué”

🔄 Assigner ou changer un rôle facilement

📦 Déplacement automatique de la carte vers le rôle correspondant

📱 Interface responsive compatible mobile et desktop

🧰 Technologies utilisées

CSS3
